Features

Everything you watch on Twitch, on the big screen.

A Rust core for the Twitch APIs, chat and storage, with a Jetpack Compose for TV interface.

Live streams

Fast channel zapping, with the next channels prepared while you watch, and quality selection remembered per channel.

  • Experimental low-latency mode: about 3.7 s behind the streamer instead of 7.2 s, on channels that allow it.
  • Audio only, which keeps playing in the background.
  • Sleep timer (15, 30, 60 or 90 minutes).
  • Stream stats: resolution, bitrate, delay, dropped frames.
  • Animated preview after a moment of focus on a card.

Multi-view

Two to four streams side by side, on devices that can decode them. Sound follows the focused tile, and any tile can be replaced.

Chat

Read and send messages, replies and an emote picker, badges, 7TV / BTTV / FFZ emotes (animated where the device allows), polls and predictions, highlighted mentions, hidden words and users.

Accounts

Sign in by scanning a QR code with your phone, no typing on the TV. Several accounts and a guest mode, each with its own settings, an optional PIN and a kids profile.

Past broadcasts

Resume where you stopped, per profile, with the chat replayed in sync. Clips too.

Discover

Followed channels first, pinned ones on top, a “Recently watched” row, recommendations, popular streams and categories you can hide, a language filter, search.

Android TV

“Continue watching” and “Live channels you follow” rows, global and voice search, and twitch.tv links open in the app.

Light on old boxes

Native Rust core, Baseline Profile for fast startup, and heavy effects turned off on low-memory devices.

Private by design

Tokens encrypted with the Android Keystore and never logged. No analytics; the optional crash log stays on the device.

Updates in the app

New versions from GitHub Releases, offered at launch. Beta versions are opt-in.

Six languages

English, French, Spanish, German, Italian and Brazilian Portuguese. The interface follows the system language, or the app’s own setting on Android 13+.

Ads inserted by Twitch play as usual: StreamSofa never blocks them and never tries to unlock subscriber or Turbo perks. Following a channel happens on your phone (a QR code on each channel page), because Twitch closed that API to third-party apps.

Quick start

On your TV in two minutes.

StreamSofa is distributed as an APK, outside the Play Store. Once installed, it updates itself.

  1. Install Downloader

    Search for “Downloader” (by AFTVnews) in the Play Store of your TV. It is free.

  2. Allow it to install apps

    Settings → Apps → Security & restrictions → Unknown sources → turn on Downloader. The exact path depends on the TV.

  3. Type this address in Downloader

    It downloads the latest version, which works on every device. Then confirm the install.

    limoniak.github.io/streamsofa-tv/get
  4. Open StreamSofa

    Pick “Guest” to watch right away, or add your Twitch account by scanning the QR code with your phone.

  1. Download the APK

    From the latest release, pick the file for your device:

    Most recent boxes and TVs (Chromecast with Google TV, Shield…)…-arm64-v8a.apk
    Older or 32-bit boxes (Mi Box S…)…-armeabi-v7a.apk
    Not sure…-universal.apk
  2. Turn on network debugging on the TV

    Settings → System → About → press “Android TV OS build” 7 times, then Developer options → USB / network debugging.

  3. Install with adb

    Replace the address with your TV’s IP (Settings → Network).

    adb connect 192.168.1.42
adb install streamsofa-0.3.0-universal.apk
  1. Requirements

    JDK 21, Android SDK (platform 37), NDK 29.0.14206865, Rust stable with the Android targets and cargo-ndk.

    rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android
cargo install cargo-ndk --locked
  2. Configure

    Register an application of type “Public” on the Twitch developer console, then fill in the SDK path and twitch.clientId.

    git clone https://github.com/Limoniak/streamsofa-tv.git
cd streamsofa-tv
cp android/local.properties.example android/local.properties
  3. Build and install

    Add -Plumen.abis=arm64-v8a to build a single ABI and iterate faster.

    cd android && ./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-universal-debug.apk
